What the numbers mean

Every number is objdiff's own counter from the build's report. Matched bytes compare exactly with the original. Linked bytes come from units the build links from source (objdiff's "complete" units). Data counts every non-code section, including zero-initialized ones.

Objects are the build's current units. Their names and count are not proof of the original translation units; folding units changes ownership, not the totals.
